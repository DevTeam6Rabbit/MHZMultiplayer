════════════════════════════════════════════════════════════
  MHZ Multiplayer Mod — Installation & Build Guide
════════════════════════════════════════════════════════════

WHAT YOU NEED
─────────────
1. MH-Zombie installed via Steam
2. BepInEx 5 (mod loader)
3. .NET SDK 4.6+ (to compile the mod)
4. Visual Studio 2022 OR VS Code with C# extension


STEP 1 — Install BepInEx
─────────────────────────
1. Go to: https://github.com/BepInEx/BepInEx/releases
2. Download BepInEx_x64_5.x.x.x.zip (the x64 version)
3. Extract it directly into your MH-Zombie folder:
     C:\Program Files (x86)\Steam\steamapps\common\MH-Zombie\
   You should now have:
     MH-Zombie\
       BepInEx\
       doorstop_config.ini
       winhttp.dll
       MHZombie.exe   ← already existed


STEP 2 — Run the game once with BepInEx
─────────────────────────────────────────
Launch MH-Zombie from Steam, let it reach the main menu, then quit.
This lets BepInEx create its folder structure.
You should now see: MH-Zombie\BepInEx\plugins\  (may be empty)


STEP 3 — Edit the .csproj to point at your game folder
────────────────────────────────────────────────────────
Open MHZombieMultiplayer.csproj in a text editor.
Find this line:
  <GameDir>C:\Program Files (x86)\Steam\steamapps\common\MH-Zombie</GameDir>
Change it to wherever MH-Zombie is actually installed.
(Right-click game in Steam → Manage → Browse local files to find it.)


STEP 4 — Build the mod
───────────────────────
Open a Command Prompt in this folder and run:
  dotnet restore
  dotnet build --configuration Release

If successful you'll see:
  build\net46\MHZombieMultiplayer.dll


STEP 5 — Copy the mod into BepInEx
────────────────────────────────────
Copy MHZombieMultiplayer.dll from build\net46\ into:
  MH-Zombie\BepInEx\plugins\

That's it for installation.


STEP 6 — Using the mod in-game
────────────────────────────────
Launch MH-Zombie normally. After loading into a level:

  F8  →  Toggle the multiplayer panel
  F9  →  Host a new lobby
  F10 →  Leave the current lobby

TO HOST:
  Press F9 (or F8 then "Host Lobby").
  A lobby ID will appear. Copy it and send to your friend,
  OR use the Steam overlay (Shift+Tab) to invite them directly.

TO JOIN:
  Press F8, paste the lobby ID your friend sent, click Join.
  OR accept a Steam invite from the overlay — it works automatically.

Once connected, you'll see your friend's helicopter as a
cyan-tinted ghost helicopter in the sky.


TROUBLESHOOTING
───────────────
• No BepInEx logs? Make sure winhttp.dll is in the game root.
• "Steam not initialized" error? The game must be launched via Steam.
• Ghost heli appears as a cube? That's the fallback — it means the
  mod couldn't find your local helicopter object. Check the log at
  MH-Zombie\BepInEx\LogOutput.log for details.
• Build errors about missing DLLs? Double-check the GameDir path in .csproj.

Log file location:
  MH-Zombie\BepInEx\LogOutput.log


CURRENT LIMITATIONS (v1.0)
───────────────────────────
• Zombie kills, scores, and mission state are NOT synced — each player
  runs their own game independently. You just see each other's helis.
• Up to 4 players supported (Steam lobby limit set in code).
• Helicopter weapons fired by others will not appear on your screen.
• This is a v1 foundation — score sync and shared zombies would be
  future additions.
